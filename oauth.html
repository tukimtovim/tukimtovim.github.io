Tukim Tovim Publisher — internal use

What this page is

This is the OAuth redirect target for Tukim Tovim Publisher, the private application we use to upload our own finished videos into the TikTok Draft Inbox of @tukimtovim.

After the account owner authorizes the app, TikTok sends them back here with a one-time authorization code. The code is shown above so it can be exchanged for an access token. It is not transmitted anywhere from this page — this is a static page with no server and no analytics, and the code stays in the browser address bar.

The app is used only by the owner of @tukimtovim and is not offered to third parties. See our privacy policy.
