# tukimtovim.github.io

Public site for **תוכים טובים / Tukim Tovim** — an Israeli political-satire channel
publishing AI-generated short-form video.

Static, no build step, no dependencies. Served by GitHub Pages from `main`.

| File | Purpose |
|---|---|
| `index.html` | Landing page (Hebrew, RTL) — what the channel is, AI disclosure, platform links |
| `terms.html` | Terms of Service (English) |
| `privacy.html` | Privacy Policy (English) — covers the *Tukim Tovim Publisher* app |
| `style.css` | Shared stylesheet |
| `assets/` | Mascot artwork |

The legal pages are written in English because platform reviewers read them.
TikTok's App Review requires a live external site with visible Terms and Privacy
links, and this repository exists to satisfy that requirement as well as to serve
as the channel's public home.
